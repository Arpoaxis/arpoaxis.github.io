# Gerard McCallion — Engineering Portfolio (Draft v1)

A responsive, framework-free portfolio website that showcases documented software engineering and scientific computing projects.

## View locally

Open `index.html` in a browser. Everything needed to render the site is included in this folder; no Node installation or build step is required.

## Project organization

- `index.html` — landing page with selected work, About, current studies, and contact links
- `projects/solar-flare.html` — Solar Flare Prediction case study
- `projects/restaurant-booking.html` — Restaurant Booking & Operations team-project case study
- `assets/styles.css` — site styles and responsive layout
- `assets/main.js` — small utility for footer year
- `assets/favicon.svg` — site icon
- `TO_REVIEW_BEFORE_PUBLISHING.md` — items to verify and improve before public release

## Publish with GitHub Pages

1. Sign into the GitHub account **Arpoaxis**.
2. Create a **public** repository named `arpoaxis.github.io` (use a new repository; do not replace the existing `solar-flare-pred` repository).
3. Upload the files **inside this folder** to the root of that repository, preserving the `assets/` and `projects/` directories. Do not upload the outer directory as another nesting level.
4. In **Settings → Pages**, choose **Deploy from a branch**, branch `main`, and folder `/(root)`; save.
5. Once GitHub Pages publishes, the expected URL is `https://arpoaxis.github.io/`.

You may instead push these files using Git locally. GitHub Pages documentation: https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site
