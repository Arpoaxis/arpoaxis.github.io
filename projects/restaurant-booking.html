The problem

Restaurant staff need coordinated information about incoming reservations, seating capacity, waitlists, and table assignments. This team project created a database-backed application to manage those workflows in a shared web interface.

What the team built

  • Reservation creation and management
  • Waitlist and table assignment workflows
  • Interactive floor-plan interface
  • Role-based views for staff and administrators
  • Server-side validation and reporting functionality

Architecture and technologies

The system used Jakarta Servlets and JSP with Apache Tomcat, Java server-side logic, and SQLite accessed through JDBC. Application state and permissions were integrated into the database-backed workflow.
